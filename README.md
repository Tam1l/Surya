# ✈️ AuraWings — Premium Flight Ticket Booking Web Application

A modern, responsive, luxury flight booking web application built with HTML5, CSS3, and JavaScript, featuring an interactive seat selection map, dynamic boarding pass generation with QR code, real-time currency conversions, and simulated flight tracking.

## ✨ Features

- **Global Route Search**: Search flights across major international destinations (Delhi, Mumbai, London, New York, Dubai, Singapore, Tokyo, Paris, Sydney).
- **Interactive Cabin Seat Map**: Choose preferred seating across First Class, Business, and Economy with real-time fee calculation.
- **Multi-Step Checkout**:
  - Passenger information and meal preferences
  - Add-ons (Extra baggage, VIP Lounge, Insurance, Carbon offset)
  - Simulated payment processing
- **Dynamic Boarding Pass**: High-fidelity airline boarding pass with QR code, PNR reference, and print/download support.
- **My Trips Manager**: Stored in `localStorage` with options to view passes and cancel bookings.
- **Multi-Currency Support**: Instant conversion between INR (₹), USD ($), EUR (€), GBP (£), AED (د.إ), and JPY (¥).
- **Live Flight Radar**: Simulated altitude, speed, and flight progress tracker.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Running Locally
```bash
# Clone the repository
git clone https://github.com/Tam1l/Surya.git

# Navigate to project folder
cd Surya

# Start the local server
npm start
```

Visit **http://localhost:3000** in your browser.
